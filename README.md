# URL Printer — Studio pro tisk webu, pracovní sešity a e-booky

**URL Printer** je moderní webová aplikace určená pro kontrolovaný tisk, úpravu a offline archivaci jakýchkoliv webových stránek. Umožňuje vytváření skript, pracovních sešitů a e-booků v reálné sazbě A4/A5 s integrovaným QR odkazovačem.

---

## 🚀 Hlavní funkce

- **Dvousloupcový vizuální editor**: Živý náhled tiskové sazby (A4 / A5) s přizpůsobením okrajů a orientace.
- **Formátování & Sazba**: Volba typografie, barevných témat, úprava stylů obrázků (zaoblení, stíny, zobrazení).
- **Interaktivní tiskový engine**: Úprava stránek, zapnutí/vypnutí prvků, QR odkazovač pro tištěné verze.
- **Export & Tisk**: Přímý tisk do PDF nebo na fyzickou tiskárnu s optimalizovaným CSS rozvržením.

---

## 🛠️ Použité technologie

- **HTML5 & CSS3**: Vanilla CSS s modulární strukturou stylů (`themes.css`, `print-engine.css`, `app.css`).
- **JavaScript (ES6+)**: Čistý JavaScript pro správu stavu, úpravu tiskové sazby a manipulaci s DOM.
- **Google Fonts**: Typografické sady Inter, JetBrains Mono, Outfit, Playfair Display a Plus Jakarta Sans.

---

## 📖 Jak spustit lokálně

Aplikace nevyžaduje žádný build proces ani Node.js server. Stačí otevřít soubor `index.html` v libovolném moderním webovém prohlížeči nebo použít lokální HTTP server (např. Live Server ve VS Code).

```bash
# Klonování repozitáře
git clone https://github.com/<username>/url-printer.git

# Otevření v prohlížeči
open index.html # nebo v Průzkumníku Windows kliknout na index.html
```
